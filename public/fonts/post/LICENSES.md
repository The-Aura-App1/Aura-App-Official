# Post fonts

These fonts let people style their posts. They are open-source Google Fonts,
downloaded from Fontsource (https://fontsource.org) as Latin, regular-weight
WOFF2 files by `scripts/fetch-post-fonts.mjs`. Each is licensed under the SIL
Open Font License 1.1 or the Apache License 2.0, which allow self-hosting and
redistribution with the app. The full list is in `src/utils/postFonts.json`.
